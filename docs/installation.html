Install your local response handler into each FastAPI project's virtual environment, then register its handlers with your app.

01 /Before you start

These examples assume the package and your applications are sibling directories. Replace paths with your own if your layout is different.

Example directory layout
workspace/
├── fastapi-response-handler/     # package source
├── project-one/                  # FastAPI application
└── project-two/                  # another FastAPI application

Use Python 3.10 or newer. The package is not automatically published to PyPI; these instructions install it from your local files.

02 /Install from local source

For development, an editable install links the package source to your app environment. Run these commands from project-one:

macOS / Linux
cd project-one
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e ../fastapi-response-handler
Windows PowerShell
cd project-one
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ..\fastapi-response-handler

If the project already has a virtual environment, activate it instead of creating a new one. For a package elsewhere, replace the relative path with its absolute path and quote paths containing spaces.

Editable means shared source. Python source edits are visible to each app using that editable install, usually after restarting its server. Reinstall after changing package dependencies or metadata.

03 /Or install a wheel

A wheel is a built snapshot. Build it from the package directory, then install it into the application's environment:

macOS / Linux · build
cd fastapi-response-handler
python3 -m venv .venv
source .venv/bin/activate
python -m pip install build
python -m build --wheel
deactivate
macOS / Linux · install in project-one
cd ../project-one
source .venv/bin/activate
python -m pip install ../fastapi-response-handler/dist/fastapi_response_handler-0.1.0-py3-none-any.whl

Use the filename generated in dist/ if the version changes. On Windows, use the same commands with your environment's PowerShell activation command and a suitable local path. Rebuild and reinstall the wheel after package changes; a wheel does not update automatically.

04 /Register and verify

In your FastAPI application's entry point, register handlers before the first request. Existing applications can keep their own routes and models.

main.py
from fastapi import FastAPI
from fastapi_response_handler import (
    SuccessResponse, api_responses, register_handlers, success_response,
)

app = FastAPI()
register_handlers(app)

@app.get("/hello", response_model=SuccessResponse[dict],
         responses=api_responses())
def hello():
    return success_response("Hello", {"name": "Ada"})

Confirm the package is installed in the activated environment and start the app. Install Uvicorn in the app environment if it is not already installed.

Terminal · from your application directory
python -c "import fastapi_response_handler; print(fastapi_response_handler.__file__)"
python -m pip install uvicorn
python -m uvicorn main:app --reload

Adjust main:app to match your application's module and app variable. Visit http://127.0.0.1:8000/hello for the example and http://127.0.0.1:8000/docs for Swagger.

05 /Use it in another project

Each virtual environment has its own installed packages. Repeat the editable or wheel installation in project-two, then register handlers in that app as well:

macOS / Linux · from workspace
cd project-two
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e ../fastapi-response-handler

Run the import check in each environment. A local path is specific to your machine or workspace, so teammates and deployment environments need access to the same source or wheel and an appropriate path. Installing in one project does not install it in another.

06 /Troubleshooting

  • Module not found: activate the app's environment, use python -m pip, and run the import check with the same Python used to start Uvicorn.
  • Path not found: relative paths are resolved from the current directory. Verify the package directory contains pyproject.toml, or use a quoted absolute path.
  • Changes are not visible: restart the app. For a wheel install, rebuild and reinstall the wheel; for an editable install, reinstall after dependency or metadata changes.
  • Dependency conflicts: the package requires Pydantic v2 and a compatible FastAPI/Starlette version. Check your application's dependency constraints before installing.
